# fosio-pages

Статическая сборка игры «Бронтобум» для GitHub Pages — папка `docs/`.

Исходники лежат в [`fosio`](https://github.com/fosemberg/fosio). Чтобы пересобрать, выполните `bun run build` в `fosio`: сборка перезапишет `docs/` целиком.

Чтобы опубликовать: Settings → Pages → Deploy from a branch → `main` / `/docs`.
